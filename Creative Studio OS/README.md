# Creative Studio OS

An open-source, browser-based project tracker for photographers, filmmakers, and small creative studios.

## Why this exists

Small creative teams often juggle client inquiries, bookings, shoot dates, editing, and delivery across multiple tools. Creative Studio OS is an early-stage experiment in providing a simple, accessible workspace for that workflow.

## Current features (v0.1)

- Add a client project with event type and date
- Track inquiry, confirmed, in-progress, and delivered statuses
- Filter projects by status
- View basic project counts
- Save projects locally in the browser using `localStorage`
- Delete individual projects or clear local data
- Responsive layout for desktop and mobile

## Run locally

Download or clone this repository, then open `index.html` in a modern browser. No installation or account required.

## Limitations and privacy

This is a prototype, not a production client-management platform. Data is stored only in the current browser and is not synced or backed up. Clearing browser storage removes it. Avoid entering sensitive client information. No AI integration is implemented yet.

## Roadmap (ideas, not completed features)

- Export/import project data
- Shoot and editing checklists
- Album-selection tracking
- Optional AI-assisted client communication
- Accessibility and automated testing improvements
